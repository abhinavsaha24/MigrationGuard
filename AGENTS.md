# AGENTS constraints

## Rules

- Never fabricate research.
- Never fabricate benchmark results.
- Never fabricate successful experiments.
- Never hide errors.
- Never remove failing tests just to pass CI.
- Never add an LLM to the detection path.
- Never generate a huge implementation without testing it.
- Never change the frozen architecture without explicit approval.
- Never silently expand scope.
- Never introduce unnecessary dependencies.
- Never modify unrelated files.
- Prefer small, reviewable changes.
- If you encounter an architectural ambiguity, STOP and explain the ambiguity rather than inventing a solution.
- Use explicit interfaces, strict TypeScript, and minimal abstractions.
- No AI-style explanatory comments in source code.
