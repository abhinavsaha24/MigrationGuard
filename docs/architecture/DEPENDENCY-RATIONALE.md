# Dependency Rationale & Architecture Audit

Every dependency in MigrationGuard is strictly audited for necessity, security, scope, and runtime footprint. No dependency is introduced solely for aesthetic brevity.

## Monorepo Dependencies

| Dependency                      | Scope   | Used By              | Purpose                                   | Why Necessary                                                                                                                 |
| ------------------------------- | ------- | -------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `typescript`                    | Dev     | Root, all packages   | Type checking and compiler (`tsc -b`)     | Enforces strict TypeScript interfaces and builds project references across monorepo packages.                                 |
| `vitest`                        | Dev     | Root                 | Monorepo unit and integration test runner | Fast ESM-native test runner executing across all workspace packages with zero transpilation overhead.                         |
| `eslint`                        | Dev     | Root                 | Static analysis and linting               | Enforces repository code quality, catches syntax errors, and guarantees AGENTS constraints.                                   |
| `prettier`                      | Dev     | Root                 | Code formatting                           | Ensures uniform deterministic formatting across the entire monorepo.                                                          |
| `@types/node`                   | Dev     | Root, packages       | Node.js standard library type definitions | Required for strict TypeScript compilation of Node standard modules (`crypto`, `fs`, `path`, `http`).                         |
| `tsx`                           | Dev     | Server               | TypeScript node execution watcher         | Used strictly in local development (`dev` script) for hot-reloading Fastify backend.                                          |
| `esbuild`                       | Dev     | CLI                  | CLI standalone bundle packager            | Bundles internal monorepo domain packages into a single standalone, zero-workspace-leakage executable for npm release.        |
| `vite`                          | Dev     | Frontend             | Frontend bundler & dev server             | Compiles React frontend with modern ESM, CSS modules, and optimized static asset production build.                            |
| `@vitejs/plugin-react`          | Dev     | Frontend             | React Fast Refresh support                | Powers React JSX transformation and hot module replacement in Vite.                                                           |
| `fastify`                       | Runtime | Server               | High-performance HTTP server              | Underpins the backend REST API with minimal overhead, schema validation, and structured lifecycle hooks.                      |
| `@fastify/cors`                 | Runtime | Server               | Cross-Origin Resource Sharing             | Handles CORS headers securely for the backend API.                                                                            |
| `@fastify/jwt`                  | Runtime | Server               | Authentication JWT token management       | Authenticates API requests securely using stateless signed tokens with cryptographic verification.                            |
| `@fastify/rate-limit`           | Runtime | Server               | Request rate limiting                     | Protects backend against denial of service and brute-force attacks on public endpoints.                                       |
| `@fastify/multipart`            | Runtime | Server               | Multipart form upload handling            | Handles evidence upload payloads and multi-part data transfer.                                                                |
| `argon2`                        | Runtime | Server               | Password hashing                          | Industry-standard memory-hard hashing function for secure user password storage.                                              |
| `zod`                           | Runtime | Server               | Schema validation                         | Validates incoming HTTP request bodies, params, and assistant payloads strictly before domain processing.                     |
| `@prisma/client`                | Runtime | Server, POC App, CLI | Type-safe ORM & database queries          | Provides typed SQL query execution and schema management against PostgreSQL databases.                                        |
| `prisma`                        | Dev/CLI | Server, POC App, CLI | Schema migration & client generation      | Drives database schema migrations, introspection, and client generation.                                                      |
| `@aws-sdk/client-s3`            | Runtime | Server, CLI          | S3-compatible object storage client       | Interacts securely with MinIO/S3 for evidence artifact storage, retrieval, and cryptographic checksum validation.             |
| `@aws-sdk/s3-request-presigner` | Runtime | Server               | Presigned S3 URL generator                | Generates temporary, time-bounded URLs for direct evidence downloads without exposing storage credentials.                    |
| `commander`                     | Runtime | CLI                  | Command-line argument parsing             | Provides robust, standards-compliant CLI command parsing, help generation, and subcommands (`verify`, `repair`, `benchmark`). |
| `formdata-node`                 | Runtime | CLI                  | Standards-compliant FormData              | Enables CLI evidence artifact multipart uploading to backend without external runtime dependencies.                           |
| `react` & `react-dom`           | Runtime | Frontend             | UI component runtime                      | Declarative component framework for the interactive web user interface.                                                       |
| `react-router-dom`              | Runtime | Frontend             | Client-side routing                       | Provides SPA navigation across Verification Runs, Matrix, Guided Repair, Architecture, and Benchmark pages.                   |
| `lucide-react`                  | Runtime | Frontend             | Iconography                               | Clean, SVG-based technical icons for visual status, diff indicators, and matrix states.                                       |
| `clsx`                          | Runtime | Frontend             | Conditional CSS class merging             | Lightweight utility for constructing dynamic CSS className strings cleanly.                                                   |
| `date-fns`                      | Runtime | Frontend             | Date formatting                           | Lightweight, tree-shakeable date/time formatting for verification timestamps.                                                 |
| `dotenv`                        | Runtime | Server               | Environment variable loading              | Reads `.env` configuration files into `process.env` in server startup.                                                        |
| `uuid`                          | Runtime | Server               | Universally Unique Identifiers            | Generates unique IDs for projects, runs, and request tracking.                                                                |
